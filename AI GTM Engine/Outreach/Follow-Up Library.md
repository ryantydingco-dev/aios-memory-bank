# Deal Threads Follow-Up Library

Last updated: 2026-06-02  
Purpose: follow-up copy for prospects who received a teardown ask, a teardown, or an install mapping CTA.

## Follow-Up Rules

- Keep every follow-up tied to the original form observation.
- Add value or specificity each time.
- Never guilt-trip.
- Never imply they are foolish for having a simple form.
- Stop after 4 touches unless they engage.

## Sequence After Initial Teardown Ask

### Follow-Up 1 - Specific Missing Context

```text
One specific thing I noticed:

The form captures [field], but it does not seem to capture [business need / timeline / CRM / use case].

That is usually the gap between "we got a lead" and "the rep knows what to say first."

Still worth sending the teardown?
```

### Follow-Up 2 - Buyer Profile Preview

```text
The buyer profile I would want sales to see after this form:

- what they are trying to solve
- timeline
- company context
- ICP fit
- unknowns to confirm
- recommended opener

That is the before/after I can map in the teardown.

Want me to send it?
```

### Follow-Up 3 - Close The Loop

```text
Should I close the loop here, or would it still be useful if I sent the form teardown later?
```

## Sequence After Teardown Sent

### Follow-Up 1 - Install Map

```text
Curious what stood out in the teardown.

The install path looks pretty lightweight from here: keep the page simple, ask 3 better questions, enrich the rest behind the scenes, and push a profile into CRM before callback.

Worth mapping that for your setup?
```

### Follow-Up 2 - Risk Reversal

```text
The first version does not need to replace your entire flow.

It can run as a beta on one approved page, with separate CRM fields and a weekly usefulness check from sales.

Worth a quick install map?
```

### Follow-Up 3 - Close The Loop

```text
I’ll close the loop unless useful.

My read: the form works for capture, but the CRM handoff is where the value is leaking.

Happy to map the install if this becomes timely.
```

## Objection Follow-Ups

### "We Already Have A Form"

```text
Totally. Deal Threads is not replacing the idea of a form.

It is replacing the thin handoff after the form: name/email/message -> rep has to research everything.

The teardown is mostly about that handoff.
```

### "We Already Use Chat"

```text
Makes sense.

The useful comparison is whether the chat creates a rep-ready CRM profile: need, fit, urgency, unknowns, and opener.

If it mostly answers questions or books meetings, Deal Threads may still cover a different gap.
```

### "Send Me Info"

```text
Sure. The useful first piece is the teardown, not a generic overview.

Send the form URL you care about most, or I can use the one on your site, and I’ll map what it captures vs. what sales still researches manually.
```
