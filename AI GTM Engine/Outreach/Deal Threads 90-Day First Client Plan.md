# Deal Threads 90-Day First Client Plan

Last updated: 2026-06-02  
Niche: industrial AI, machine vision, robotics, and custom automation integrators.  
Goal: land the first paid Deal Threads client by turning weak quote/contact intake into project-ready profiles.

## The Reverse-Engineered Number

Plan for **800 total touches across 200 target accounts**.

That is the working number for getting the first client with margin.

The math:

```text
1 client
/ 25% install-call-to-client close rate
/ 50% teardown-to-install-call rate
/ 50% reply-to-teardown-yes rate
/ 10% account reply rate
= 160 accounts
```

With 4 touches per account:

```text
160 accounts x 4 touches = 640 touches
```

Add a 25% buffer for bad fits, missed contacts, weak timing, and messy data:

```text
200 accounts x 4 touches = 800 touches
```

## Touch Definition

A touch is one intentional outbound action:

- LinkedIn connection note.
- LinkedIn DM.
- email.
- follow-up.
- close-loop message.
- direct call/voicemail for a high-fit account.

Comments and content engagement are useful, but do not count unless they directly start or continue a sales conversation.

## The 4-Touch Account Sequence

### Touch 1: Intake Observation

Send after reviewing the site.

```text
I looked at your quote/contact intake and noticed it captures the lead, but probably still leaves sales figuring out the actual project profile manually.

Want me to send a quick intake teardown?
```

### Touch 2: Specific Missing Context

Send 3 days later.

```text
One specific thing I noticed:

The intake does not visibly capture process, equipment, constraints, timeline, or whether this is worth a sales/engineering callback.

Still worth sending the teardown?
```

### Touch 3: Project Profile Preview

Send 7 days later.

```text
The project profile I would want sales or engineering to see before callback:

- process or problem
- current equipment/site context
- technical constraints
- timeline
- budget or urgency signal
- unknowns to confirm

Want me to map that from your current intake?
```

### Touch 4: Close Loop

Send 14 days later.

```text
Should I close the loop here, or would it still be useful if I sent the intake teardown later?
```

## Offer Ladder

### Step 1: Free Intake Teardown

The free offer is not a generic audit. It should show:

- what the current form captures.
- what sales or engineering still has to research.
- what project fields should be collected.
- what the project-ready profile could look like.
- where Deal Threads would sit without forcing a website rebuild.

### Step 2: 20-Minute Intake Mapping Call

CTA after teardown:

```text
The teardown points to one lightweight install path. Worth a 20-minute call to map the page, project fields, routing, and proof metric?
```

### Step 3: Paid Pilot

Initial client offer:

```text
30-day Project Intake Pilot

One quote/contact page.
One approved conversation flow.
One project profile pushed to CRM/email.
Weekly usefulness review with sales or engineering.
```

Recommended first-client pricing:

- $1,500 setup.
- $2,500/month managed pilot.
- 30-day cancel window.

Use this as a risk-reversal version of the normal $2,500/month service, not as a permanent discount.

## 90-Day Roadmap

### Days 1-14: Prove The Wedge

Goal: validate that the niche understands the project-intake gap.

Targets:

- 30 accounts researched.
- 80-100 touches sent.
- 3-5 replies.
- 2 teardown yeses.
- 1 teardown delivered.

Actions:

- Work only industrial AI, machine vision, robotics, and custom automation integrators.
- Find owner, president, sales manager, business development, or applications engineering lead.
- Send teardown-first messages only.
- Build the first teardown manually and make it excellent.

Pass/fail:

- If fewer than 2 replies after 50 first touches, the first-line observation is not specific enough.
- If replies are curious but no one accepts teardown, the CTA is too vague.

### Days 15-30: Build Signal

Goal: find which sub-niche replies.

Targets:

- 60 total accounts researched.
- 200 total touches sent.
- 6-8 replies.
- 4 teardown yeses.
- 2-3 teardowns delivered.
- 1 install mapping call.

Actions:

- Compare sub-niches:
  - machine vision AI integrators.
  - robotics integrators.
  - industrial controls firms.
  - automation consultants.
- Track which missing-context angle gets replies:
  - line speed/defect type.
  - robot payload/cell type.
  - PLC/control stack.
  - ROI/timeline/budget.
- Turn the best teardown into a reusable proof asset.

Pass/fail:

- If teardowns are accepted but calls do not happen, the teardown needs a stronger "install path" section.
- If calls happen but no paid pilot interest appears, reduce pilot risk: one page, one workflow, one proof metric.

### Days 31-60: Turn Teardowns Into Calls

Goal: create enough real sales conversations to close.

Targets:

- 120 total accounts researched.
- 450-500 total touches sent.
- 12-15 replies.
- 7-8 teardown yeses.
- 5-6 teardowns delivered.
- 3 install mapping calls.
- 1 paid pilot proposal.

Actions:

- Double down on the sub-niche with the highest teardown yes rate.
- Stop messaging accounts with generic equipment sales and no custom project motion.
- Build one teardown per week into a before/after project-intake example.
- Ask every teardown viewer for a 20-minute install mapping call.

The main question for this phase:

```text
Can I show the buyer how Deal Threads makes one specific inbound request more quote-ready before anyone calls?
```

### Days 61-90: Close First Client

Goal: close one paid pilot and build the proof loop.

Targets:

- 200 total accounts researched.
- 750-800 total touches sent.
- 20 replies.
- 10 teardown yeses.
- 8-10 teardowns delivered.
- 4-6 install mapping calls.
- 1 paid client.

Actions:

- Keep sending, but prioritize follow-up with teardown viewers.
- Offer a narrow pilot only:
  - one form/page.
  - one project-intake flow.
  - one CRM/email profile output.
  - one weekly review.
- Ask for the paid pilot on calls where the buyer confirms the intake problem.
- Do not build custom features before money unless the feature is required for the pilot.

## Stop Rules

### Targeting Problem

If 100 first touches produce fewer than 5 replies:

- tighten the niche.
- use more specific form observations.
- avoid bigger, polished companies.
- prioritize founder-led and regional firms.

### Offer Problem

If replies happen but teardown yeses are low:

- make the teardown feel lighter.
- show a sample before/after.
- change CTA from "teardown" to "2-minute intake map."

### Proof Problem

If teardowns happen but calls are low:

- add a clear install path.
- show the exact project-profile fields.
- include a low-risk pilot scope.

### Trust Problem

If calls happen but no one buys:

- sell a narrower pilot.
- charge setup plus first month.
- avoid replacing systems.
- position Deal Threads as sitting in front of their current intake, not replacing the website or CRM.

## The First-Client Success Definition

The first client is won when:

- they agree the current intake under-qualifies project leads.
- they approve one page/form to test.
- they approve the project-profile fields.
- they pay for setup or first month.
- the first Deal Threads-generated profile is reviewed by sales or engineering.
