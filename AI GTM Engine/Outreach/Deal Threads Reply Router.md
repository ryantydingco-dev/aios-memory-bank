# Deal Threads Reply Router

Last updated: 2026-06-02  
Purpose: know exactly what to say when outbound prospects reply.

## Reply Categories

| Category | Signal | Next Action |
| --- | --- | --- |
| Teardown yes | "send it", "sure", "go ahead" | create/send teardown within 24 hours. |
| Curious | asks what Deal Threads is | explain in 2 sentences, offer teardown. |
| Send info | wants generic info | redirect to teardown or ask for form URL. |
| Already have form/chat/enrichment | tool objection | clarify buyer-profile handoff gap. |
| Privacy/security concern | risk objection | send trust/install scope answer. |
| Bad timing | timing objection | ask permission to send teardown later. |
| Not a fit | clear no | thank, close, mark passed. |

## Teardown Yes

```text
Perfect. I’ll keep it tight.

I’ll look at:
- what the form captures now
- what sales likely still researches manually
- what a buyer profile could include
- the lightweight install path if it looks useful

I’ll send it over here.
```

## Curious

```text
Short version: Deal Threads turns demo/contact form submissions into buyer profiles before sales follows up.

The chat is just the intake surface. The value is the CRM handoff: need, fit, urgency, company context, unknowns, and recommended opener.

Want me to show that using your current form?
```

## Send Info

```text
Happy to.

The most useful "info" is usually a teardown of your actual form, because generic overviews make this sound more abstract than it is.

Want me to use the form on your site, or is there another page you care about more?
```

## Already Have Chat

```text
That may cover part of it.

The question I would look at is: does the current chat create a rep-ready CRM profile, or does it mostly answer questions/book meetings?

If it is the second one, there may still be a handoff gap.
```

## Privacy Concern

```text
Fair concern.

For beta, I would keep scope narrow: approved page, approved fields, separate CRM properties, no unnecessary sensitive data, and unknowns clearly marked instead of guessed.

The teardown can include what I would avoid collecting.
```

## Not Now

```text
Makes sense.

Should I close the loop, or send the teardown later as a reference when this becomes timely?
```

## No

```text
Totally fair. Appreciate you taking a look.
```
