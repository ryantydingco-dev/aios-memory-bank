# Deal Threads 30-Day Outbound Sprint

Last updated: 2026-06-02  
Purpose: exactly what Ryan should do every day to turn Deal Threads outbound into teardown requests, install calls, and beta clients.

## Daily Minimum

Do this before making any new strategy:

1. Add 10 targets.
2. Send 10 first touches.
3. Send 10 follow-ups.
4. Produce or improve 1 teardown.
5. Log every outcome.
6. Post or comment once using a lesson from the outreach.

## Daily 90-Minute Block

### 0-15 min: Queue

- open outbound workbook.
- add or review 10 targets.
- run the send board script.
- pick the 10 sends.

### 15-40 min: Send

- send 5 LinkedIn connection notes.
- send 5 email/DM first touches.
- log sends.

### 40-60 min: Follow Up

- send follow-up 1/2/3 to due prospects.
- reply to engaged prospects.
- log replies and objections.

### 60-85 min: Proof Asset

- build 1 teardown.
- improve 1 buyer-profile example.
- deliver a promised teardown.

### 85-90 min: Review

- update today's counts.
- choose tomorrow's bottleneck.

## Daily Decision Rules

- If replies are below 5%, improve targeting and first-line specificity.
- If replies are positive but no teardowns happen, reduce friction: offer a written teardown instead of Loom.
- If teardowns get watched but no install calls book, improve the install CTA and proof.
- If install calls happen but do not convert, tighten risk reversal and beta scope.
- If beta profiles are not useful, change questions before changing enrichment.
