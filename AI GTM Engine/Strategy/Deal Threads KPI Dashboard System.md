# Deal Threads KPI Dashboard System

Last updated: 2026-06-01  
Business: Deal Threads  
Business model: B2B managed service first, SaaS-enabled workflow later  
Stage: MVP / pre-revenue launch  
Revenue model: free teardown -> paid audit/setup -> monthly subscription  
Industry: AI lead enrichment, B2B inbound conversion, CRM workflow automation  
Primary audience: founder-led and RevOps-light B2B teams with high-value inbound leads

## Executive Summary

Deal Threads should not run its early metrics like a mature SaaS company yet.

At this stage, the business does not need a giant dashboard. It needs a tight operating system that answers five questions every week:

1. Are we creating enough attention from the right buyers?
2. Are those buyers submitting their form URLs?
3. Are teardowns converting into install conversations?
4. Are installs turning into working buyer profiles in CRM?
5. Are working profiles turning into recurring revenue?

The first north star is **qualified form URLs submitted per week**.

MRR becomes the executive north star once Deal Threads has paying installs. Until then, MRR is a lagging outcome. Qualified form URLs are the strongest leading indicator because they prove the inbound machine is attracting the right buyer, with the right problem, and a workflow Deal Threads can diagnose.

## 1. North Star Metrics Framework

### Phase 1 North Star: Qualified Form URLs Submitted Per Week

Definition:

A qualified form URL is a submitted demo/contact-sales page from a B2B company where:

- the company sells B2B.
- the form is tied to sales or demo requests.
- the deal value is likely USD 8K+ or high LTV.
- the submitter is a founder, sales, marketing, RevOps, or consultant stakeholder.
- there is a credible CRM/sales follow-up workflow.

Why this is the early north star:

- It measures real inbound intent.
- It proves the Dead Form Audit/teardown positioning is working.
- It creates the raw material for teardowns.
- It is closer to revenue than followers, impressions, or generic email signups.
- It lets Deal Threads build proof before case studies exist.

Owner:

- Ryan / founder.

Review frequency:

- daily for new submissions.
- weekly for conversion rates and source quality.

Targets:

| Stage | Weekly Target | Health |
| --- | ---: | --- |
| Weeks 1-2 | 1-3 qualified form URLs/week | Validating message and CTA. |
| Weeks 3-6 | 3-5 qualified form URLs/week | Machine is beginning to work. |
| Weeks 7-12 | 5-10 qualified form URLs/week | Enough volume to create repeatable installs. |
| Post-proof | 10+ qualified form URLs/week | Supports partner/content scale. |

### Phase 2 North Star: MRR From Working Installs

Definition:

Monthly recurring revenue from clients whose Deal Threads workflow is installed and producing buyer profiles from real form submissions.

Important qualifier:

Do not count promised trials or verbal pilots as MRR. Count the client only when:

- workflow is installed.
- real or test lead profile lands in CRM.
- payment terms are active or billing trigger is satisfied.

Targets:

| Timeframe | MRR Target | Path |
| --- | ---: | --- |
| 30 days | USD 0-1K | first install started or audit sold. |
| 60 days | USD 1K-2.5K | 1 Founder or 1 Growth install. |
| 90 days | USD 5K | 5 Founder installs, 2 Growth installs, or mixed path. |
| 12 months | USD 20K-40K | 10-20 customers at blended USD 2K/month. |

## 4. Automated Calculations And Formulas

Use these formulas in the dashboard spreadsheet.

### Revenue

```text
MRR = SUM(active customer monthly subscription values)
ARR = MRR * 12
MRR Growth Rate = (Current MRR - Previous MRR) / Previous MRR
Setup Cash = SUM(setup fees collected in period)
ARPU = MRR / Active Customers
```

### Acquisition

```text
Ask-to-Submit Rate = Qualified Form URLs / Form URL Asks
Audit-to-URL Rate = Qualified Form URLs / Audit Downloads
Comment-to-DM Rate = DM Conversations / ICP Comments
DM-to-URL Rate = Qualified Form URLs / DM Conversations
```

### Funnel Conversion

```text
URL-to-Teardown Rate = Teardowns Delivered / Qualified Form URLs
Teardown-to-Call Rate = Install Calls Booked / Teardowns Delivered
Call-to-Install Rate = Installs Started / Install Calls Booked
Install-to-Paid Rate = Paying Customers / Installs Started
```

### Customer Metrics

```text
Monthly Churn Rate = Customers Lost / Customers at Start of Month
Net Revenue Retention = (Starting MRR + Expansion MRR - Contraction MRR - Churned MRR) / Starting MRR
Profile Completeness = Completed Target Fields / Target Profile Fields
Useful Profile Rate = Useful Profiles / Profiles Reviewed
```

### Unit Economics

```text
CAC = Sales and Marketing Spend / New Paying Customers
Founder-Time CAC = Founder Acquisition Hours * Implied Hourly Rate / New Paying Customers
Gross Margin = (Revenue - Direct Costs) / Revenue
LTV = ARPU * Gross Margin % / Monthly Churn Rate
LTV:CAC = LTV / CAC
CAC Payback Months = CAC / (ARPU * Gross Margin %)
```

## 5. Alert System And Thresholds

### Health Colors

| Status | Meaning | Action |
| --- | --- | --- |
| Green | On track. | Keep executing. |
| Yellow | Caution. | Diagnose and adjust this week. |
| Red | Action needed. | Stop adding complexity; fix bottleneck. |

### Early Inbound Thresholds

| Metric | Green | Yellow | Red |
| --- | ---: | ---: | ---: |
| LinkedIn posts/week | 5+ | 3-4 | 0-2 |
| ICP comments/week | 50+ | 25-49 | 0-24 |
| DM conversations/week | 10+ | 5-9 | 0-4 |
| Audit downloads/week | 10+ | 3-9 | 0-2 |
| Qualified form URLs/week | 3+ | 1-2 | 0 |
| Teardowns delivered/week | 2+ | 1 | 0 |
| Install calls/week | 1+ | 0 with form URLs | 0 with no form URLs |

### Revenue Thresholds

| Metric | Green | Yellow | Red |
| --- | ---: | ---: | ---: |
| MRR by day 90 | USD 5K+ | USD 1K-4.9K | USD 0 |
| Teardown-to-call rate | 25%+ | 10-24% | <10% |
| Call-to-install rate | 20%+ | 10-19% | <10% |
| Gross margin | 70%+ | 50-69% | <50% |
| CAC payback | <1.5 months | 1.5-3 months | >3 months |
| Monthly churn | <5% | 5-10% | >10% |

### Escalation Protocols

If qualified form URLs are red:

- improve the CTA.
- comment on more ICP posts.
- show more before/after examples.
- ask for form URLs directly in DMs.

If teardowns are red:

- reduce teardown scope to 15 minutes.
- use a repeatable template.
- block time twice per week for delivery.

If teardown-to-call is red:

- make teardowns more specific.
- include an example CRM buyer profile.
- ask for the install scoping call directly.
- add "pay-when-it-works" guarantee.

If install-to-paid is red:

- inspect product activation.
- check whether buyer profiles are useful.
- reduce implementation complexity.
- revisit ICP or pricing.

## 8. Metric Selection Rules

### Metrics To Prioritize

Use metrics that are:

- actionable weekly.
- directly tied to the revenue path.
- easy to update manually at low volume.
- leading indicators of installs and MRR.
- useful for deciding what to do next.

### Metrics To Avoid For Now

Avoid over-focusing on:

- LinkedIn impressions without ICP engagement.
- follower count.
- generic website traffic.
- total email subscribers without form URL submits.
- product feature usage before customers exist.
- complicated attribution models before channel volume exists.

## 12. Dashboard Principle

The best Deal Threads dashboard is not the one with the most metrics.

It is the one that tells Ryan what to do next:

- publish more if attention is low.
- ask more directly if conversations are high but URLs are low.
- tighten teardown proof if URLs are high but calls are low.
- fix activation if calls convert but profiles are not useful.
- raise price or improve delivery if MRR grows but margin suffers.
