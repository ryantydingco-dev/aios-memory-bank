# Deal Threads Proof Capture System

Last updated: 2026-06-02  
Purpose: make every beta install produce proof, not just feedback.

## Proof Goal

Deal Threads needs proof that buyer profiles are useful before the callback.

The first beta reports should answer:

1. Did the widget create useful buyer profiles?
2. Did sales save research time?
3. Did reps/founders follow up with better context?
4. Did the CRM handoff improve?
5. Did any meetings or deals benefit?

## Weekly Beta Metrics

Track:

| Metric | Definition |
| --- | --- |
| Widget sessions | Visitors who opened widget. |
| Conversations completed | Sessions reaching qualified completion. |
| Completion rate | Completed / started. |
| Profiles created | Buyer profiles generated. |
| CRM sync success | Profiles synced / profiles created. |
| High-priority leads | Profiles scored high priority. |
| Useful profiles | Profiles rated useful by rep/founder. |
| Useful profile rate | Useful profiles / reviewed profiles. |
| Median submit-to-profile time | Time from completion to CRM profile. |
| Estimated research time saved | Profiles x minutes saved. |
| Meetings influenced | Meetings where profile helped first touch. |

## Profile Usefulness Rating

After a rep/founder reviews a profile, ask:

1. Did this help you understand the lead before follow-up?
2. What was the most useful field?
3. What was missing?
4. Was anything wrong or misleading?
5. Did it change your first message/call?

Rating:

- 3 = useful and changed follow-up.
- 2 = useful context but did not change action.
- 1 = mildly useful.
- 0 = not useful.
- -1 = misleading or wrong.

## Case Study Capture

When a beta shows value, capture:

- before state.
- after state.
- metric improved.
- quote.
- screenshot of buyer profile.
- CRM view screenshot.
- anonymized workflow diagram.
- what Deal Threads changed.

Case study title format:

```text
How [Company] Turned Thin Form Fills Into Rep-Ready Buyer Profiles In [X] Days
```

## Proof Thresholds

Strong proof:

- 10+ profiles created.
- 70%+ useful profile rate.
- 10+ minutes saved per qualified lead.
- 1+ meeting influenced.
- client quote.

Good proof:

- 5+ profiles created.
- 50%+ useful profile rate.
- CRM handoff works.
- clear product learning.

Weak proof:

- low lead volume.
- profiles not reviewed.
- CRM handoff unclear.
- no sales owner adoption.

## Proof Review Questions

Ask weekly:

1. Which profile best showed the value?
2. Which field mattered most?
3. Which question should be changed?
4. Which enrichment field was noisy?
5. Did sales use the note?
6. Did the profile affect speed or quality of follow-up?
7. What would make this worth paying for next month?
