# Ryan Higgsfield Production Workflow

## Purpose
Turn Ryan's AI/GTM/business workflow ideas into funny cinematic visuals using Higgsfield, Banana Pro Director, and Cinema Worldbuilder Pro.

## Core Principle
The visual is the pattern interrupt. The workflow lesson is the trust-builder.

Every piece should answer:

1. What useful thing are we teaching?
2. What funny visual makes it memorable?
3. What proof/template/checklist do we give away?

## Workflow

### Step 1 — Choose the lesson
Examples:
- A job title is not a lead. A buying signal is.
- AI gets you to 70%; human context gets you to 90%.
- The lead list is not the product. The workflow is.
- If it is not logged in HubSpot, it did not happen.
- Most businesses do not need more AI tools. They need one workflow mapped clearly.

### Step 2 — Choose the metaphor
Match the lesson to a recurring bit:

- Bad lead lists → Spreadsheet Goblin
- AI without QA → Overconfident AI Intern
- CRM mess → CRM Gremlin
- Oloxa doc chaos → Cursed Borrower Docs
- SaaS/tool sprawl → Tool Duct Tape Monster

### Step 3 — Build image assets with Banana Pro Director
For recurring characters:

1. Develop/lock the face or entity.
2. Build a base outfit/reference on mid-gray background.
3. Create a 6-panel sheet if the character will recur.
4. Create a scene plate or environment reference.

Important style constraints:
- photoreal default
- mid-gray background for character work
- avoid glossy/plastic AI look
- describe real camera/lighting language
- keep recurring identity markers consistent

### Step 4 — Build motion prompt with Cinema Worldbuilder
Use a dense production-style prompt:

- who/what is in the frame
- where it happens
- what changes over time
- camera movement
- lighting/depth/haze where relevant
- final frame
- sound bed if needed
- runtime

Keep it short enough to render well. Do not write poetry. Write the production document.

### Step 5 — Generate in Higgsfield
Recommended usage:
- 9:16 for Shorts/Reels
- 4:5 or 1:1 for LinkedIn visuals
- 16:9 for YouTube longform inserts

Generate multiple variants if needed, but avoid endless credit goblin behavior.

### Step 6 — Edit into content
Use visuals as:
- cold open
- punchline
- chapter break
- analogy
- before/after metaphor

Then pair with:
- Ryan face-cam explanation
- screen proof
- workflow map
- free artifact/template

### Step 7 — Publish and learn
Track:
- did the visual increase watch time/scroll stop?
- did people comment on the metaphor?
- did the practical lesson still land?
- did it attract the right people?

## Short-Form Format

```text
0-2s: funny Higgsfield visual hook
2-8s: Ryan names the business problem
8-25s: screen proof/workflow explanation
25-45s: practical framework
45-60s: free artifact / takeaway
```

## LinkedIn Format

```text
[Funny visual]

[Sharp business observation]

[3-5 practical bullets]

[Free checklist/template/framework]

[One-line takeaway]
```

## Quality Gate
Before using a visual, ask:

- Is this clearly connected to the lesson?
- Would a founder/operator still take Ryan seriously?
- Is it funny without being childish?
- Is there proof or a real workflow attached?
- Are we giving away enough value?

## Avoid
- making AI visuals the whole point
- overproducing instead of publishing
- misleading realism/deepfake vibes
- visuals with no useful business takeaway
- creepy characters that distract from trust
