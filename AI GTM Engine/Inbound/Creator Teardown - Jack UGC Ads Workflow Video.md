# Creator Teardown - Jack UGC Ads Workflow Video

Video: https://www.youtube.com/watch?v=zswO-Wuo0E0

## Core Information Lesson
Do not invent from zero. Find proven outliers, deconstruct why they work, then create ethical variants for your own niche.

Framework:
1. Find outliers
2. Deconstruct why they work
3. Create your own variant
4. Test and iterate

## Creator Content Structure

### Hook
Starts with a strong outcome + proof-style claim:
- Claude Code changed profitable ads
- UGC converts better
- UGC is expensive/time-consuming
- Here is how to find and clone winning patterns

Pattern:
`Big change + painful bottleneck + promised workflow`

### Credibility
He stacks credibility quickly:
- founder/operator background
- mentions prior startup exit
- shows actual tools
- shows actual ad libraries
- demonstrates live examples

### Demonstration Style
The video is not just talking head. It is a guided build:
- explanation
- screen share
- tool demo
- live generated output
- comparison to original
- practical caveats

### Visual Style
- face cam in bottom-left during screen shares
- energetic talking head sections
- bold slide/text visuals
- constant movement between tools, examples, and outputs
- receipts: Meta ad library, TikTok ad library, tool UI, generated ads
- playful examples: trainers, Fresca, pineapple pizza, SpongeBob/Krusty Krab

### Why It Works
- makes abstract AI automation concrete
- shows receipts instead of just making claims
- gives a repeatable system
- teaches strategy before tool steps
- uses humor to keep technical content watchable
- gives viewers a feeling of "I could build this too"

## Ryan Adaptation
Ryan should adapt the format, not copy the niche.

Ryan format:
1. Start with a business/GTM workflow bottleneck
2. Explain why it matters
3. Show real source material or system proof
4. Deconstruct the pattern
5. Build or show the workflow
6. End with practical takeaway

Example Ryan topics:
- How we turn a messy lead CSV into 20 HubSpot tasks
- How to find buying signals instead of generic lead lists
- How AI can turn borrower docs into lender-ready packages
- How to create a daily GTM operating system with Hermes + HubSpot
- How to reverse-engineer strong outbound from replies/objections

## Ryan Video Template

```text
[Hook]
Most people are trying to use AI to do [generic thing].
I think the better use case is [specific workflow].

[Problem]
Here is why this workflow usually breaks.

[Proof]
Here is the actual system/source material/workflow.

[Deconstruction]
These are the 3 things that matter.

[Build/Demo]
Here is how I would turn that into a repeatable workflow.

[Takeaway]
The goal is not more tools. The goal is a cleaner workflow that creates time, revenue, or clarity.
```

## What To Steal
- outcome-first hook
- proof on screen
- tool walkthroughs
- playful examples
- deconstruct-before-build framework
- show the result side-by-side

## What Not To Copy
- hype-heavy conversion claims unless verified
- direct ad cloning language
- overly tool-centered framing
- anything that feels ethically sketchy or spammy

## Content System Rule
For Ryan: every workflow video should show receipts. If the video claims a system exists, show a blurred screenshot, workflow map, before/after output, or live tool demo.
