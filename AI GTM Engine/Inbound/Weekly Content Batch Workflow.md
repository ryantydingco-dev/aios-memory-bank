# Weekly Content Batch Workflow

## Purpose
Turn Ryan's real work into consistent content without needing daily inspiration.

## Weekly Batch Session: 60–90 minutes

### 1. Review raw material
Look at:
- screenshots
- Oloxa GTM lessons
- HubSpot outcomes
- call notes
- Sway conversations
- objections
- workflow examples
- AIOS/Hermes builds

### 2. Pick 5–7 strongest ideas
Each idea needs:
- real moment
- lesson
- audience
- platform
- takeaway

### 3. Draft platform pack
For each strong idea:
- LinkedIn post
- short-form script
- optional carousel angle
- comment prompts

### 4. Grade and rewrite
Use [[Content Grader]].

### 5. Queue/publish
Weekly baseline:
- 4 LinkedIn posts
- 2 short-form scripts
- 1 weekly recap
- 5–10 comments/day

## Daily Capture Prompt
```text
Today I noticed:
The useful lesson:
The real example:
This could help:
Possible hook:
```

## Ryan Content Rule
Do not chase virality before clarity. Become visibly useful first.
