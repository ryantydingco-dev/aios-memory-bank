# What Counts as an Artifact?

An artifact is **the thing the viewer can inspect while you talk**. It is not the word “artifact,” generic B-roll, or a claim that a system exists.

## Valid Artifacts

- Workflow map
- Scorecard
- Dashboard
- Tracker
- Redacted campaign result
- Sample buyer row
- Prompt with its output
- SOP
- Before-and-after process
- Public report
- Screen recording of a working tool

## Three Evidence Labels

### Concept / Sample

Use when you are explaining what should be built. Say “this is the workflow I would install” or “this is a sample.”

### Built / Operational

Use when the system actually exists. Show the working screen but redact private data.

### Evidence-Backed Result

Use when an outcome is recorded. Show the denominator, timeframe, limitation, and next proof gate.

## Artifact Rule

Never say “I built this” when the artifact is only a concept. Never show private customer data. If there is no inspectable artifact or concrete story, the video is not ready to record.
