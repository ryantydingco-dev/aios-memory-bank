## The Exact Workflow

1. Open one recording card below.
2. Open its linked artifact in another Obsidian pane.
3. Put the script in Reading View and increase text size.
4. Record vertically. Read the script exactly the first time.
5. Show the artifact during the artifact sentence.
6. Save the clean recording as `V001-title.mov`.
7. Import the matching text file from `Descript Import/` when editing.
8. Approve each platform version before publishing.
