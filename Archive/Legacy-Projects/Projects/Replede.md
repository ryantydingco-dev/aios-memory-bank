# Replede

## What it is
Replede is an AI lead-enrichment chat widget concept/product lane. It sits in the broader “AI inbound intelligence” space: capture website hand-raisers, enrich the conversation into a buyer profile, and make the result useful for a sales team.

## Current positioning
Codex’s competitive/market direction framed the wedge as:

> Not “another AI chat widget,” but **managed inbound intelligence for mid-market B2B teams** that need to turn website hand-raisers into rep-ready buyer profiles.

The differentiation target is against:
- Drift-era complexity.
- Enterprise ABM pricing/implementation burden from tools like 6sense/Demandbase.
- Manual RevOps glue between a website inquiry and a useful sales-ready record.

Core decision filter:

> Does this make Replede the fastest way for a mid-market sales team to turn a website hand-raiser into a rep-ready buyer profile?
