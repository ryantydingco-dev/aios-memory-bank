# TikTok Pricing Intelligence

## What it is
A Chrome extension MVP for TikTok Shop operators that helps sellers reason about pricing, margin risk, competitor pressure, and recommended price moves.

Source workspace:
`/Users/ryantydingco/Documents/Tik Tok PI`

## Current build direction
- Manifest V3 Chrome extension.
- Popup dashboard for pricing intelligence.
- Content-page overlay/signal panel for product pages.
- Shared pricing engine so popup and overlay use the same math.
- Mock/demo competitor and pricing data for the first MVP.
- Local demo product page used for testing.

## Product thesis
Start with a demoable operator tool before overbuilding live marketplace integrations. The initial wedge is showing sellers where margin/pricing risk exists and what price action to consider.

## Open questions
- Does the MVP need real TikTok Shop data before outreach, or is a demo workflow enough for early customer discovery?
- Which seller segment is first: small TikTok Shop operators, agencies, or high-volume brands?
