# Dachshund Merch — Side Project

**Status:** Building. Target: first stranger sale by **2026-08-12** (30 days from kickoff).
**Owners:** Ryan + Maclaine. Kenny touchpoint: decoration method + print scheduling only.
**Working name:** TBD — see naming shortlist in [content-plan.md](content-plan.md). Dogs' names: `[CONFIRM]`.

## The premise

A dachshund-niche merch brand (human apparel first, dog accessories second) powered by what CA already owns:

1. **SanMar sourcing** — quality blanks (Comfort Colors, Bella+Canvas) at $3–7 instead of Printful's $13–16 landed cost.
2. **In-house decoration** — we keep the printer's margin AND the retailer's margin.
3. **Two live-in content stars** — organic TikTok/IG is the traffic engine; the dogs are the show, the shirts are props.
4. **Camp-store muscle** — we already run windowed merch stores. This is the same motion with the window removed and content/ads as the traffic source.

## Why this specific niche

Dachshund ownership is an identity, not a demographic. Proof of market:
- **Bean Goods** — dachshund-only brand, $1K side project (2011) → $150K (2017) → $1M+/yr, 70K+ customers.
- **Crusoe the Celebrity Dachshund** — 7M+ followers across platforms, merch + books + a dog-ramp company.
- Multiple smaller players (Woof+Ween, Long Dog Apparel, Inkopious) surviving on Printful-tier margins we can undercut.

Full findings: [research.md](research.md)

## The strategic double-win

Even at break-even, this project is R&D for a real CA product: **always-on merch stores** (year-round camp stores, org stores, client brand stores). Everything we learn — platform, on-demand fulfillment cadence, content-driven traffic — productizes into a recurring-revenue upsell for existing CA clients.
