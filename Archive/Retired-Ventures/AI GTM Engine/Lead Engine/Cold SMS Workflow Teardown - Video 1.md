# Cold SMS Workflow Teardown - Video 1

Video: https://www.youtube.com/watch?v=-ZdexdGhqV8

## Purpose
Ryan asked whether cold SMS workflows from YouTube are serviceable for the 30-day local-business revenue sprint.

## Video Claim
The creator claims cold SMS can book 3-5+ extra qualified sales calls and that at scale it can produce 60-100+ appointments/month.

The video's KPI model:
- 5% positive reply rate
- 33% of positive replies convert to booked calls
- 67% show rate
- 20% close rate

At 10,000 SMS, this equals:
- 500 positive replies
- 167 booked calls
- 110 held calls
- 22 clients

Applied to Ryan's current 450 postcard businesses:
- 5% positive reply = 22.5 positive replies
- 33% booked = 7.4 booked calls
- 67% show = 5.0 held calls
- 20% close = ~1 client

At weaker positive reply rates:
- 1% positive = ~0.2 clients
- 2% positive = ~0.4 clients
- 3% positive = ~0.6 clients
- 5% positive = ~1.0 client

## What The Video Gets Right

### 1. Cold SMS is high attention
SMS does get seen more than email. The 90% open-rate claim is directionally believable, but open rate is not the business metric.

The real metrics are:
- positive reply rate
- audit-request rate
- booked call rate
- show rate
- close rate
- spam/negative reply rate
- number health

### 2. Bad SMS looks scammy
The creator's bad opener example is useful:
- no personalization
- random link
- unclear sender
- big claim
- no context

This is exactly what Ryan should avoid.

### 3. Better SMS answers objections upfront
Good message components:
- first name
- local/geographic context
- clear reason for message
- value-first asset
- identity disclosure
- how Ryan found them / why them
- no random links in first message

### 4. One follow-up before response
The workflow says send initial SMS, wait 24h, send one follow-up, then only continue if they respond. This is better than endless pestering.

### 5. SMS should route to a call
The video's core insight is correct: SMS is not where the sale happens. SMS gets permission/interest and routes to a call.

## What Is Risky / Not Serviceable As-Is

### 1. The creator admits it is black/gray hat
He explicitly says cold SMS is black/gray hat and warns about TCPA/legal exposure. This is not a clean scalable channel.

### 2. Google Voice + Bulk Text Pro is fragile
The suggested medium method uses Google Voice + Bulk Text Pro. This is operationally fragile:
- number can get restricted
- carrier filtering
- Google account risk
- poor tracking
- hard opt-out management
- not a professional revenue system

### 3. 10,000-SMS math does not match Ryan's current list
Ryan has ~450 postcard businesses, not 10,000. Using the creator's own model, Ryan should expect around 1 client only if the offer/message hits a strong 5% positive reply rate.

That can still be worth it, but it is not a magic 60-100 appointment machine at Ryan's current volume.

### 4. Phone-number sourcing section is thin
The creator mostly says:
- Google Maps/sites for local businesses
- LinkedIn/Apollo/Clay for professionals
- validate numbers using ClearoutPhone

This does not solve Ryan's specific need: owner personal cell numbers for local businesses.

### 5. The example offer is not Ryan's offer
The creator's example is about providing leads/appointments. Ryan's offer is a Google profile/review/missed-call/website sprint. The opener must be rewritten around the postcard + audit context.

## Serviceability Verdict

### Channel: Serviceable only as a tiny manual test
Cold SMS can be serviceable for Ryan if used as:
- manual/1:1 outreach
- high-intent top 25-100 prospects
- specific postcard/audit context
- no links in first message
- one follow-up max before response
- fast routing to call

### Not serviceable as:
- mass blast to 450 personal cells
- Google Voice/Bulk Text Pro spam cannon
- generic "want more leads?" message
- replacement for proof asset/audit

## Ryan-Specific Adapted Workflow

### Target
Start with 25-50 best postcard recipients.

### SMS Opener
```text
Hey {{first_name}} — Ryan Tydingco here in Chapin.

I sent {{business}} a postcard recently and made a quick 60-sec Google/website audit after noticing {{specific_issue}}.

Worth sending it over?
```

### Follow-Up After 24h
```text
Quick follow-up — no pitch in the audit, just the 3 fixes I’d make first so {{business}} can turn more Google searches into calls.

Want me to send it?
```

### If Positive
```text
Cool — I can send it here or email it over. Also happy to walk you through it in 2 minutes today.

Would later this afternoon or tomorrow morning be easier?
```

### If Objection / Busy
Validate → address → redirect.

```text
Totally fair. I’m not asking you to buy anything from the text.

I just noticed {{specific_issue}} and thought the quick audit might be useful.

Want me to send it and you can ignore it if it’s not relevant?
```

### If No / Stop
Remove immediately.

## Ryan KPI Model For 450 Businesses

If Ryan messages all 450 manually/contextually:

Conservative:
- 1-2% positive reply = 4-9 positives
- 1-3 booked calls
- 0-1 close

Good:
- 3-5% positive reply = 13-22 positives
- 4-7 booked calls
- 3-5 held calls
- 1 close

Great:
- 8%+ positive reply = 36 positives
- 12 booked calls
- 8 held calls
- 1-2 closes

## Recommendation
Test 50 messages before any full send.

Measure:
- delivered
- positive replies
- negative replies
- audit requests
- booked calls
- held calls
- closes

If 50 sends produces fewer than 1-2 audit requests, fix the message before scaling.

## Bottom Line
The workflow has useful principles, but Ryan should not copy the bulk-sending mechanics blindly. The serviceable version is a manual, high-context, audit-first SMS test using the postcard as warm context. The non-serviceable version is blasting 450 personal cells with generic copy and hoping the YouTube KPI math saves it.
