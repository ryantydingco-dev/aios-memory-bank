# Deal Threads Daily AI Operator Prompt

Last updated: 2026-06-01  
Purpose: paste this into Codex each day to run the inbound machine with minimal thinking

## Morning Prompt

```text
Run today's Deal Threads inbound execution.

Use these files as the source of truth:
- 00 - Deal Threads Inbound Command Center.md
- Inbound/Deal Threads Week 1 Execution Pack.md
- Experiments/Deal Threads Inbound Scoreboard.md
- Inbound/Deal Threads Inbound Machine Blueprint.md
- Product/Deal Threads User Persona System.md

Today's job:
1. Tell me the one LinkedIn post to publish today.
2. Give me 10 LinkedIn search/comment targets.
3. Give me 5 comment drafts tailored to today's theme.
4. Give me 3 DM snippets for anyone who engages.
5. Tell me the one CTA to use today.
6. Tell me exactly what to log in the scorecard.

Keep it execution-only. No new strategy unless the scorecard shows a bottleneck.
```
