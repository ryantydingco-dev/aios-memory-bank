## The Pain

Their current quote/contact form is technically working.

It captures:

- name.
- email.
- company.
- phone.
- message.

But it usually does not capture:

- process or application type.
- line speed or production volume.
- current equipment.
- robot/camera/control constraints.
- project urgency.
- budget readiness.
- plant/site context.
- whether sales or engineering should respond first.

So every serious inquiry creates hidden work:

```text
Someone still has to figure out whether this is a real project, what kind of project it is, who should review it, and what to say first.
```

## Grand Slam Offer Stack

### Core Deliverable: Project Intake Teardown

Delivered as a short PDF, doc, or Loom-style walkthrough.

Includes:

1. Current Intake Snapshot.
2. Project Context Gap Score.
3. Missing Discovery Fields.
4. Project-Ready Profile Blueprint.
5. 3-5 Better Intake Questions.
6. Sales/Engineering Routing Map.
7. Deal Threads Install Path.

### Bonus 1: Project Profile Mockup

Show a sample profile their team would receive after a form fill.

Example fields:

- Project type.
- Process/problem.
- Site or facility context.
- Current equipment.
- Constraints.
- Timeline.
- Budget/urgency signal.
- Unknowns to confirm.
- Recommended first reply.
- Sales vs. engineering routing recommendation.

### Bonus 2: 3-Question Intake Rewrite

Give them three better questions that would improve qualification without making the form painful.

Example:

```text
1. What process or problem are you trying to automate or inspect?
2. What equipment, line, or facility constraints should we know before responding?
3. When are you hoping to scope or start the project?
```

### Bonus 3: Callback Opener

Give them the first reply/call opener sales could use if the project profile existed.

Example:

```text
Saw you are looking at [application] for [process/site]. Before we talk options, I want to confirm [unknown] and [constraint] so we route this to the right person.
```

### Bonus 4: Low-Risk Pilot Map

If the teardown shows a real gap, include the exact pilot path:

- one approved quote/contact page.
- one intake flow.
- 3-5 project-intake questions.
- enrichment only where useful.
- project profile delivered to email or CRM.
- weekly usefulness check.
