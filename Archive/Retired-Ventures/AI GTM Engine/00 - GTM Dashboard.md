# AI GTM Engine Dashboard

This is the clean command center for Ryan's AI-powered GTM operating system.

## Mission
Use Oloxa as the live case study to master signal-based lead generation, GTM intelligence, personalized outreach, meeting booking, and packaging the system into a reusable B2B offer.

## North Star
Book as many qualified Oloxa meetings as possible by building a machine that answers every day:

1. Who should Ryan/Sway contact?
2. Why this company/person?
3. Why now?
4. What should we say?
5. What did the market teach us?

## Operating Rule
If a note, workflow, or task does not help us **find better buyers, identify stronger reasons now, say better things, book more meetings, learn the market faster, or package the proven system later**, it does not belong here.
