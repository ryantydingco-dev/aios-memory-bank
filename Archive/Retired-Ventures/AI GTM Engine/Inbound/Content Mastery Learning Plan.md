# Content Mastery Learning Plan

## Goal
Build Ryan's personal brand and authority by learning content craft, turning lessons into reusable frameworks, and automating the repeatable parts of the content workflow.

## Positioning
Ryan is not trying to become a generic creator.

Ryan's authority lane:
- AI systems for real business workflows
- Oloxa/building in public
- signal-based GTM and outbound
- practical AI implementation for business owners
- founder/operator lessons

## Learning Loop

### 1. Study
Feed Hermes strong videos, posts, creators, examples, and swipe files.

For each input, extract:
- core content principle
- tactical framework
- what applies to Ryan
- what does not apply
- example in Ryan's voice
- workflow/skill update if durable

### 2. Practice
Turn each lesson into a small output:
- 1 LinkedIn post
- 1 short-form script
- 3 hooks
- 1 content system rule

### 3. Publish
Ship consistently. Do not stay in analysis mode.

Baseline:
- 4 LinkedIn posts/week
- 2 short videos/week
- 5–10 thoughtful comments/day

### 4. Measure
Track:
- posts published
- comments received
- DMs/conversations
- profile views if available
- content-assisted leads
- topics that felt easy/hard
- hooks that worked

### 5. Codify
If a lesson repeats or works, turn it into:
- content rule
- prompt
- template
- grader criterion
- workflow automation
- Hermes skill update

## Video Study Prompt
Use this when sending videos:

```text
Break this down for content mastery.

Extract:
1. The content principle
2. The repeatable framework
3. What applies to my personal brand
4. What to ignore
5. 3 examples in my voice
6. One workflow we should add to AIOS
7. Whether this should update a skill

Video:
[link]
```

## What To Feed Hermes
Good inputs:
- YouTube videos about content strategy, copywriting, storytelling, hooks, short-form, LinkedIn, creator workflow, repurposing, audience building
- creators whose style Ryan likes
- screenshots of posts Ryan likes/dislikes
- Ryan's own drafts
- analytics screenshots
- comments/DMs
- sales call notes
- Sway conversations

Bad inputs:
- random hustle porn
- pure algorithm hacks with no business relevance
- creators whose brand Ryan would hate sounding like
- over-polished corporate content

## Automation Roadmap

### Phase 1 — Manual Mastery
Build reps manually:
- capture daily content seeds
- draft with Hermes
- grade with Content Grader
- publish manually
- track manually

### Phase 2 — Assisted Workflow
Automate drafting/organization but keep human approval:
- raw asset folder scan
- weekly idea extraction
- draft generation
- post grading
- repurposing pack
- content calendar file

### Phase 3 — Scheduling/Cross-Posting
After voice is stable:
- connect scheduler/social tool if desired
- queue approved posts
- repurpose across LinkedIn, Shorts, IG, YouTube

### Phase 4 — Analytics Feedback Loop
Pull performance data and improve:
- best hooks
- best topics
- best formats
- content-assisted leads
- inbound conversations

## Rule
Do not automate taste before developing taste.

Automation should remove admin, not replace judgment.
