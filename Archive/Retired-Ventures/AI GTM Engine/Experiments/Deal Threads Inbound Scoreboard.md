## Success Thresholds

### Keep Going

Keep the same system if weekly numbers are at least:

- 5 posts.
- 50 comments.
- 10 conversations.
- 3 audit downloads.
- 1 form URL submitted.

### Improve CTA

If posts/comments get engagement but no form URLs:

- make the CTA more direct.
- offer fewer slots.
- show more before/after examples.
- ask for form URL in DMs, not only public posts.

### Improve Targeting

If conversations happen but buyers are low-fit:

- comment on more founder-led B2B, RevOps, demand gen, and sales posts.
- reduce generic AI audience posts.
- add disqualification language to CTA.

### Improve Proof

If form URLs arrive but calls do not book:

- make teardown more specific.
- include a buyer-profile preview.
- show the CRM handoff.
- ask for the install scoping call directly.
