# Dealthreads Teardown + Outreach Assets

## Dead Form Teardown format

Use this for each top prospect.

### 1. Current form captures

- Name
- Email
- Company
- Phone
- Message / demo request
- Any dropdowns visible

### 2. What sales still has to research

- Company size
- Buyer role / authority
- Segment / fit
- Current workflow/tool
- Pain area
- Urgency / timeline
- Budget/scale proxy
- First useful question

### 3. Rep-ready buyer profile mockup

```text
Company:
Buyer:
Role/likely authority:
Segment:
Fit score:
Likely use case:
Current workflow guess:
Urgency signal:
Missing context:
Recommended first question:
Unknowns:
```

### 4. Before/after line

Before:
> Raw form submit: name, email, company, generic demo request.

After:
> Buyer profile: who they are, why they might care, what sales should ask first, and which unknowns still need confirmation.
