# Descript Import Guide

The `Descript Import` folder contains:

- One plain-text teleprompter script per video.
- Four combined batch files for recording multiple videos in one session.

The individual files contain spoken words only. Stage direction, artifact instructions, evidence, and tracking remain in the matching Obsidian recording card.

## File Naming

- `001 - title.txt` matches recording card `001 - title.md`.
- Save the clean camera file with the same number.
- Keep the clean master free of captions and watermarks.

## Editing Handoff

1. Import the raw camera clip.
2. Use the matching text file as the script or transcript reference.
3. Remove dead space and mistakes.
4. Add captions.
5. Insert the linked artifact during the artifact sentence.
6. Export one clean vertical master.
7. Create platform-specific captions and metadata separately.
