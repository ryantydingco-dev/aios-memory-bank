# AI Profile Shortlist for Meedro

Created: 2026-06-28

## Key Finding

Meedro's agent flow appears to be profile-first, not keyword-first. The useful workflow is:

1. Find proven AI / automation / AI coding creators outside Meedro.
2. Add exact Instagram or TikTok handles into Meedro.
3. Set broad fetch filters first, then tighten after Meedro proves it can fetch videos.
4. Let Meedro extract hooks/scripts, then rewrite them into Ryan's $3M promotional products AI transformation niche.

## What Codex Can Do Inside Meedro

- Open the Meedro AI Agent dashboard.
- View agent status and run history.
- Add/edit/delete agents.
- Add/remove target profiles by exact username.
- Select platform when adding a profile (Instagram visible; verify TikTok options on the next add).
- Adjust run schedule.
- Adjust reels per creator.
- Adjust minimum view threshold.
- Switch data strategy between overwrite/fresh and other available options.
- Edit rewrite instructions.
- Paste/update Google Sheet and Drive folder links.
- Save changes, confirm save, and run the agent.
- Open the linked Sheet/Drive output and inspect whether Meedro populated rows/files.

## What Meedro Does Not Appear To Do

- No visible keyword discovery field for `AI`, `artificial intelligence`, `Codex`, `Claude Code`, `automation`, etc.
- No visible topic search page inside the agent flow.
- No visible built-in "find high-performing AI profiles" discovery surface from the agent screen.

Use Meedro as the analyzer after profile discovery, not as the discovery engine.

## Operating Rule

Do not burn additional Meedro runs on unverified handles. Before each run:

1. Verify exact handle.
2. Prefer the account with higher follower count/post volume.
3. Use `Any` min views for diagnostic fetches.
4. Only tighten to `10k+` once Meedro successfully fetches videos.
