# 08 — Outreach Scripts

> Verbatim, copy-paste-ready scripts for selling the **Dealthreads GTM Experiment Engine** to the first ICP: **agencies & consultants selling high-ticket B2B services**. Founder-to-founder, LinkedIn + Loom-first, peer tone. This is the exact wedge Ryan runs on Oloxa.
>
> **Rules baked into every script below:** no spam framing, no guaranteed-meetings/revenue, no "AI automation agency" slop (unlock / revolutionize / game-changer / supercharge / leverage AI to). Outcome-first: more *qualified conversations*, sharper targeting, faster learning. Honest about proof (Oloxa = client #0). Sell the system + a 90-day pilot + real artifacts.

**How to use this doc:**
- `[Brackets]` = swap in a specific, true detail before sending. If you can't fill a bracket with something real, **don't send it** — generic = spam.
- Pick ONE specific reason per person. Never reuse the same opener across a list.
- Every script has a short "why it works / don't break it" note so you can adapt without going off-brand.

---

## 0. The one-account prep (do this before any script)

Before you write a single message, you need three true things per person. If you don't have all three, skip them or do more homework.

1. **A specific hook** — a post they wrote, a client win, a niche they own, a hire, a podcast they were on. Something only-true-about-them.
2. **A likely wound** — for this ICP it's almost always *lumpy, referral-dependent pipeline* and *no repeatable outbound motion / no RevOps to build one*.
3. **A free value-add you can actually deliver** — usually a draft research card for one of *their* likely target accounts (company, contact, signal, evidence, pain hypothesis, personalized opener). This is the Loom payload.

> If you only remember one thing: **show, don't pitch.** The research card does the selling.

## 1. LinkedIn connection request (no pitch)

**Constraint:** LinkedIn connection notes are short. Keep it under ~300 characters. No pitch, no link, no ask. One specific line.

### Primary (reference a post / POV)
> Hey [First name] — your post on [specific topic] hit home, especially the bit about [specific detail]. I work with [agency/consultant] founders on the GTM side and your take lined up with what I'm seeing. Would be good to connect.

### Variant A (reference their niche / who they serve)
> Hey [First name] — been seeing your work with [their niche, e.g. "B2B SaaS founders on positioning"]. I run a GTM experiment loop for founders in that lane and your approach stood out. Mind if I connect?

### Variant B (reference a win / launch / hire)
> Congrats on [the win / new client / hire], [First name]. Looks like a strong stretch for [their company]. I work with [agency] founders on pipeline and wanted to connect with people doing it right.

### Variant C (genuinely warm — shared context, no agenda)
> Hey [First name] — fellow [founder / operator] in the [their space] world. Not pitching anything, just like how you talk about [specific thing]. Open to connecting.

**Why it works / don't break it:**
- Specific first line proves you're not blasting. The whole job here is *get the accept*, nothing else.
- **No** "I help X do Y" pitch, no calendar link, no "quick question." That reads as a sales bot and tanks accept rate.
- "Not pitching anything" (Variant C) is allowed *only if you mean it* — don't pitch in the very next DM 10 seconds later. Earn it.
- One specific detail beats three vague compliments every time.

## 2. Post-accept DM (name the wound, soft Loom ask)

Send this **after they accept** — ideally not in the same minute (looks automated). A few hours to a day later is fine. Goal: name the wound in their language, one line on what you do, soft ask to send a 90-second Loom. **No link dump. No calendar push yet.**

### Primary
> Thanks for connecting, [First name].
>
> Quick honest reason I reached out: most [agency/consultant] founders I talk to have great clients but pipeline that lives and dies on referrals — quiet stretches between word-of-mouth, no real outbound motion because building one is a whole job nobody has time for.
>
> I run a weekly GTM experiment loop for exactly that — LinkedIn + short personal videos, every message human-approved, and we actually measure which angles earn real conversations vs. polite no's. I run the same engine on my own company, live.
>
> Not going to dump a pitch on you. Want me to send a 90-second Loom showing what it'd look like for [their company]? I'll build a real example, not a generic walkthrough. No worries if not.

### Variant A (they're clearly busy / terse profile)
> Appreciate the connect, [First name].
>
> Straight to it: pipeline for high-ticket [their service] usually swings on referrals — feast then famine. I run a weekly, human-approved LinkedIn + video outreach loop that makes targeting sharper every week (I run it on my own company too).
>
> Can I send you a 90-sec Loom built around [their company] specifically? Easier to show than tell. Cool either way.

### Variant B (warmer — they engaged with you / mutual)
> Good to be connected, [First name] — been enjoying your stuff on [topic].
>
> I help [agency] founders turn "we only grow by referral" into a repeatable outbound loop — LinkedIn + Loom-first, every message approved by a human, measured on conversation quality not vanity opens. Same system I run on my own company.
>
> Want a quick 90-sec Loom on what it'd look like for [their company]? I'll do the homework first so it's actually useful.

**Why it works / don't break it:**
- Leads with **their wound in their words** ("lives and dies on referrals"), not with you.
- One sentence on the engine — resists the urge to explain all six loop steps.
- **"I run this on my own company, live"** = the honest credibility line. Use it; it's your strongest asset with no external case study.
- The ask is for *permission to send a Loom*, not for a meeting. Lowest-friction yes available.
- "No worries / cool either way" removes pressure — counterintuitively raises reply rate with this buyer.
- **Banned here:** "quick question," "jump on a call," "15 minutes of your time" as the opener, any link, any "AI-powered" language.

## 3. Loom audit talk-track (60–90s, what Ryan actually says)

This is the differentiator. You're recording a short, personal video screen-sharing **their world** — a draft research card you built for one of *their* likely target accounts. Show the engine's output; don't describe the engine.

**Setup before recording:** have the research card on screen (company, contact, signal, evidence, pain hypothesis, personalized opener). Have their LinkedIn or site up so it's visibly *for them*. Face cam on. Batch these — ~30 min gets you several.

### Talk-track (say this, roughly)

**[0:00–0:10] — Personal open, prove it's for them**
> "Hey [First name], Ryan here — keeping this quick. I connected because you're exactly who I built this for, and instead of telling you what I do, I figured I'd just show you. Give me 90 seconds."

**[0:10–0:30] — Name the wound, set up the demo**
> "So most folks running [their service] grow off referrals — which is great until it's quiet, and there's no outbound engine to fall back on because building one is a full-time job. Here's what I'd actually do for [their company]. I went and built one of these for real — this is a target account I think fits you."

**[0:30–1:05] — Walk the research card (the proof)**
> "This is a research card. Top: the company — [example account] — and the specific person you'd want to reach. This line is the *signal* — why now — they're [hiring / closing rounds / scaling / showing this specific pain]. Here's the evidence I pulled. Then a pain hypothesis: what they're probably struggling with that you solve. And down here, an opener written for that exact person — not a template, written off the signal. We build a scored list of these, test a few angles a week, and measure which ones earn real back-and-forth — not just opens."

**[1:05–1:25] — The honest frame + what they're buying**
> "I'm not going to promise you a flood of meetings — anyone who does is lying or about to torch your reputation. What I sell is sharper targeting and faster learning: every week the engine gets smarter about who to talk to and how. Every message is human-approved, so it stays on-brand. And I run this exact loop on my own company, so you'd see real artifacts, not a deck."

**[1:25–1:30] — Soft CTA**
> "If that's interesting, worth 15 minutes to walk through how the weekly loop would run for you. I'll drop a couple times in the chat. Either way — nice to connect, [First name]."

**Loose time budget:** 0:00 personal / 0:10 wound / 0:30 card walkthrough / 1:05 honest frame / 1:25 CTA. Aim 75–90s. Over 2:00 = re-record.

**Why it works / don't break it:**
- **The research card IS the pitch.** You're showing the actual deliverable, on their account. Nobody else in their inbox is doing this.
- Honest frame ("not going to promise a flood of meetings") *builds* trust with a sophisticated buyer and separates you from spray-and-pray.
- CTA is 15 minutes, framed as "walk through the loop," **not** "demo my software" and **not** "hop on a call to see if it's a fit" (sounds like a pitch trap).
- Keep it imperfect and human. A slightly rough, clearly-personal Loom outperforms a polished generic one.
- **Don't:** read a script word-for-word stiffly, show a generic slide deck, run past 2 minutes, or say "leverage AI" / "automate your outreach."

## 4. 15-minute discovery call (audit, not demo)

**Frame the whole call as an audit of *their* GTM, not a demo of *your* thing.** You diagnose first; the engine comes up only as the answer to a problem they just described out loud. Talk ~30%, listen ~70%.

### Open (30 sec — set the frame)
> "Thanks for the time, [First name]. Quick frame so we don't waste it: this isn't a demo. I want to understand how you actually get clients today and where it breaks, and if there's a fit I'll tell you exactly what I'd do — and if there isn't, I'll tell you that too. Sound good?"

### Diagnose — current state (ask, then shut up)
1. "Walk me through where your last 3–5 clients actually came from." *(listen for: referrals, network, luck, no system)*
2. "When referrals go quiet, what's your plan B right now?" *(listen for: the wound — "there isn't one" / "I post and hope")*
3. "Have you tried outbound before — DIY, an agency, a tool? What happened?" *(listen for: past burns, attribution scars, what they think 'outbound' means)*
4. "Who's your best-fit client — and roughly what's a typical engagement worth?" *(qualify: $10k+ engagements / $3k+/mo means the math works on a handful of conversations)*
5. "How much of *your* week disappears into trying to drum up pipeline?" *(quantify the chaos / the cost)*

### Reflect the wound back (this is the pivot)
> "So if I'm hearing you right: the work's great and clients are happy, but pipeline basically depends on referrals and a slow quarter is genuinely scary because there's no engine underneath it. And you don't have — and don't really want to build — a RevOps function or hire an SDR you'd wait a quarter to ramp. That the real problem?"

*(Let them confirm. The sale gets made here, not in the pitch.)*

### Prescribe (only now — and keep it tight)
> "Here's what I'd do. Week one, we build the engine: a real ICP, a scored list of accounts with a *reason* each one is on it, and research cards like the one I sent. Then every week we run 3–5 small experiments — different angles and segments — on LinkedIn with personal Looms, every message you approve before it goes out. We measure reply rate *and* conversation quality, and each week the targeting gets sharper. You spend maybe 30–60 minutes a week approving messages and taking the good calls. I run it — same engine I run on my own company."

### Honest expectations (say this unprompted — it's a trust move)
> "What I won't tell you: that you'll get 20 meetings next month. Honest cold reply rates are low single digits — it takes hundreds of touches per meeting. For you that's fine, because one [$X] client pays for this many times over, so we don't need volume, we need the *right* handful of conversations. Month one buys you the machine and the first signal; the compounding is months two and three."

### Close the call → next step
> "Two ways this goes. Either it's clearly not a fit and we shake hands, or it is and I'll send you a one-page pilot outline today — 90 days, founder-run, fully transparent. Want me to send that over?"

**Why it works / don't break it:**
- **Audit framing flips the power dynamic** — you're diagnosing, not selling. This buyer respects that and does it themselves.
- Question 4 is the silent qualifier: if engagements are tiny, the 30-day proof math breaks — note it and don't oversell.
- Reflecting the wound back **in their words** before prescribing is the single highest-leverage move on the call.
- Honest-expectations block is **non-negotiable** — it's what makes you different and what makes the renewal easy later.
- Next step is "send the pilot outline," not "so do you want to sign up?" Keep momentum, low pressure.
- **Don't:** screen-share a product tour, talk for 10 of the 15 minutes, or promise numbers to "close harder."

## 5. Pilot-close script

Use after discovery when there's clear fit + a real wound confirmed. Anchor **Growth (~$3,500/mo)**, setup **$1,500–$2,500** billed separately, framed as a **90-day founder-run pilot**. Month-to-month after.

### The frame
> "Here's how I'd start us — a 90-day pilot, and I run it personally, not a junior pod. Same engine I run on my own company, so you'll see the real artifacts the whole way: the research cards, the weekly reviews, the conversation-quality scoring. No black box."

### The shape (say the numbers plainly)
> "There's a one-time setup — [$1.5–2.5k] — to build the engine: context pack, your scored account universe, research cards, the messaging system, tracking. Then it's [~$3,500] a month to run the loop. Flat retainer, not per-meeting — on purpose, because per-meeting pricing pushes people toward junk volume, which is exactly what we're not doing."

### The risk reversal (honest, not a fake guarantee)
> "How I de-risk it, since I'm not going to insult you with a 'guaranteed meetings' promise: I commit to the *activity* — a set number of approved touches, the experiments run, and a real weekly review every single week. If I miss that activity commitment in a month, that month gets credited. You'll know exactly what ran and what it returned, every week. And after 90 days it's month-to-month — I earn the renewal with results, not a lock-in."

### The SDR anchor (use if price hesitation shows)
> "For context on the number: a fully-loaded SDR runs ten to twelve grand a month, takes three to four months to ramp, and the average one's gone inside two years. This is live in week one, costs you a fraction of that, and the *system* stays even if anyone leaves. Roughly ninety grand a year cheaper than one SDR — and you get a documented, compounding loop instead of one person's inbox."

### The ask
> "I've got room to take on [one / two] pilots this month and I run them hands-on, so it's limited on purpose. If you're in, I'll send the pilot outline and a simple agreement today, we book a 60-minute kickoff this week, and we're live within a few days. Want to do it?"

### If they want to "think about it"
> "Totally fair. Can I ask — is it the fit, the budget, or the timing? I'd rather know the real hesitation than send you a follow-up you ignore." *(Then route to the matching objection in §6.)*

**Why it works / don't break it:**
- States price **plainly and early** — hedging on price reads as unsure. Anchor Growth; let them step down to Starter if needed, never lead with the cheap tier.
- Risk reversal is an **activity** commitment, never an outcome promise. This is the line you cannot cross.
- "Limited pilots, I run them hands-on" is *true* (founder-run) — scarcity that isn't fake.
- The "think about it" question surfaces the real objection instead of letting the deal die in a follow-up void.
- **Don't:** discount reflexively, invent a deadline, or promise a meeting count to get the yes.

## 6. Objection handling (objection → response)

Keep responses short, honest, and route back to value. Never get defensive. Several of these *strengthen* trust if you handle them straight.

### "We already do outbound."
> "Good — then you're not starting cold, which helps. Honest question: do you know which angle and which segment actually earns *conversations*, or just which ones get sent? Most founders doing their own outbound are flying on volume and vibes — no read on conversation quality, nothing compounding week to week. That's the gap I fill: same channel you're using, but a measured experiment loop on top so it gets sharper instead of staying flat. I'm not replacing your outbound — I'm making it learn."

### "We tried agencies / it didn't work."
> "Yeah, most outbound agencies earn that reputation — they buy a list, blast it, optimize for sends, and torch your reputation chasing a meeting number. I'd be skeptical too. Three things I do differently: every message is human-approved so nothing spammy goes out under your name; we measure conversation *quality*, not just reply rate; and I run it personally and show you every artifact weekly — you'll see exactly what's happening, not a monthly 'we sent 4,000 emails' report. What specifically went wrong last time? I'll tell you honestly if I'd hit the same wall."

### "Is this just spam / AI?"
> "Fair to ask — most 'AI outreach' is exactly that, and it's why inboxes are a wasteland. Opposite approach here: low volume, high relevance, and a human approves every single message before it sends — nothing goes out under your name that you haven't seen. The research and drafting get help, sure, but the judgment and the send are human. And it's LinkedIn + personal video first, not a 5,000-a-day email cannon — blasting actually self-harms now since the 2024 spam caps. The whole point is the un-spammy version."

### "No budget."
> "Honest answer or polite one?" *(beat)* "Honest: if pipeline is the problem, this isn't really a cost line — it's the cheapest version of fixing it. A fully-loaded SDR is ten-plus grand a month and four months to ramp. This is a fraction of that, live week one. But if cash is genuinely tight *right now*, let's not force it — we can start on the Starter tier to prove the motion on one segment, or you tell me when timing's better and I'll check back. I'd rather start right than start broke."

### "We have no case studies of our own to point to." *(their objection about their own outreach)*
> "Same boat I'm in, honestly — which is exactly why this works. When you don't have case studies, you can't lead with 'look at our results' — you have to lead with *insight about the prospect*: the right signal, a sharp opener, a personal video that proves you did the homework. That's precisely what the research-card motion is built on. It earns conversations on relevance, not on logos you don't have yet. We build the proof *from* these first conversations — it's how I'm running my own company right now."

### "Why not just hire an SDR?"
> "Honestly, if you want to build a real in-house sales team eventually, you probably should — later. But as the first move it's rough: ten-to-twelve grand a month fully loaded, three-to-four months before they're productive, and the average SDR's gone inside two years — so you ramp, lose them, re-hire, re-train. This is live in week one, costs a fraction, and the *system* stays — the ICP, the scored list, the tested messaging, the weekly learning — even if a person walks. Think of it as building the engine an SDR would *use*, before you hire one. Roughly ninety grand a year cheaper than the hire, too."

### "Not a priority right now."
> "Makes sense — and I'd rather you say that than fake interest. Only thing I'd flag: pipeline's usually 'not a priority' right up until a quarter goes quiet, and by then you're building the engine from zero under pressure — which is the worst time. It compounds, so starting in a *good* stretch is when it pays off most. No push, though. Want me to check back in [30 / 60] days, or is this a 'not this year' thing? Either's a real answer."

**Why these work / don't break them:**
- Every response **concedes the valid part first** ("fair to ask," "you're right to be skeptical") — disarms instead of arguing.
- "No budget" and "not a priority" both offer a **graceful exit or a step-down**, not a hard push — protects the relationship for later.
- The SDR and agency objections lean on the **validated, real facts** (ramp time, tenure, 2024 spam caps) — never invented numbers.
- **Don't:** argue, oversell, promise results to overcome price, or get defensive about being early — leaning *into* "I'm client #0" is more credible than dodging it.

## 7. Multi-touch follow-up set

For non-responders after the post-accept DM or the Loom. **2–3 touches over ~7–12 days, each adding value — never "just bumping this."** Then stop and let it breathe.

### Touch 1 — value-add (a second angle), ~3 days after no reply to the Loom
> "Hey [First name] — no pressure on the last one. Quick add: I was looking at [their niche] and a second angle that's working right now is [specific angle / signal, e.g. 'targeting firms that just raised, before they staff up internally']. Happy to show you what that'd look like for [their company] too. Worth a quick look?"

### Touch 2 — proof artifact / honest reframe, ~4 days later
> "Last useful thing and then I'll get out of your inbox: here's [a sample weekly review / a second research card] from how I actually run this — figured the concrete version is more useful than me describing it. If pipeline-on-autopilot-from-referrals isn't a problem worth solving right now, totally fine. If it is, 15 minutes and I'll walk you through the loop."

### Touch 3 — the graceful close, ~5 days later
> "I'll stop here, [First name] — don't want to be the guy clogging your DMs. If the timing's just off, say the word and I'll check back down the road. And genuinely, no hard feelings if it's a no — I'd rather a clean no than a polite ghost. Either way, glad we connected."

### Optional email touch (only if you have a clean address + a real reason)
**Subject:** quick one re: [their company] pipeline
> "Hey [First name] — Ryan here, we connected on LinkedIn. Not going to retype everything; short version is I run a weekly, human-approved LinkedIn + video outreach loop for [agency] founders and built a quick example for [their company]. [Loom link]. If it's interesting, 15 minutes; if not, no worries at all. — Ryan"

**Why it works / don't break it:**
- Each touch **adds something** (new angle, real artifact, clean exit). Zero "just following up."
- Touch 3 *invites the no* — which paradoxically pulls replies and keeps the door open for later.
- Capped at 3 LinkedIn touches. **Do not** keep poking — over-following-up is how you get muted and burn the connection.
- Email is **optional, low-volume, one clean message** — not a sequence. Reputation-safe by default (post-Feb-2024 rules punish blast).
- **Banned across all touches:** "just bumping," "circling back," "did you see my last message," "following up again," guilt, fake urgency.

## Quick reference — the non-negotiables

| Always | Never |
|---|---|
| One specific, true detail per person | Same opener copy-pasted across a list |
| Lead with *their* wound, in their words | Lead with "I help X do Y" / your features |
| "I run this on my own company, live" | Fabricated results or client logos |
| Sell economics, targeting, learning speed | Guarantee meetings, revenue, or reply rate |
| Soft asks (send a Loom? / 15 min?) | "Quick call?" / link dump / calendar push up front |
| Honest math (1–5% reply, ~300/meeting) | "Flood of meetings" / volume promises |
| Human-approved, LinkedIn + Loom-first | "AI automation," 5k/day blast, spray-and-pray |
| Invite the clean "no" | "Just bumping this" / guilt / fake urgency |
| Concede the valid part of an objection | Argue, get defensive, or oversell to close |

> **The throughline:** you're not selling outreach volume — you're selling a system that gets smarter every week, run by a founder who runs it on himself. Every script should feel like that's obviously true.
