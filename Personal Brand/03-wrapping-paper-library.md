# Wrapping Paper Library
*Caleb's rule: collect packaging BEFORE you need it. 30–60 min/week of non-directed scrolling on 1of10.com + YouTube — screenshot anything that grabs you, ESPECIALLY from outside the niche (everyone inside the niche copies each other). Save only outliers (~2.5x+ the creator's average). "Screenshot the absurd."*

## Weekly ritual (put it in the time-block system)
1. 30–60 min, one sitting, no agenda. 1of10.com outliers + YouTube home on a logged-out/second profile.
2. Screenshot title+thumbnail (YouTube) or save-to-folder (LinkedIn/IG: hooks, carousels, formats).
3. Drop into this file (or a Notion board) with one line: *why it grabbed me*.
4. When packaging a finished video: shop this library for the best-fitting wrapper. Never start from blank.

## Notes on packaging rules (from his courses)
- Packaging is the ONLY competitive advantage before the click; you compete with all of YouTube, not just your niche.
- Hook: 2–3 seconds short form; 15–20 seconds max on YouTube (not 30).
- Packaging formats fatigue FASTER than content formats — keep restocking.
- Thumbnail best practice violates classic design rules; don't let "good design" instincts run it.
