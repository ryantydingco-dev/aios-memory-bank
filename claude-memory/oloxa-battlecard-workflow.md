Ryan's chosen daily outbound-production pattern for Oloxa GTM is a Claude Code **dynamic workflow** that fans out one pipeline per lead: stage 1 verify/refresh the buying signal (web), stage 2 write the full multi-channel touch set (LinkedIn connect+DM, cold email, call opener, voicemail, SMS, 2 follow-ups, top objection, recommended sequence), stage 3 adversarial brand-QA against the Oloxa positioning/banned-phrases rules. Output is structured JSON → battlecards.

**Why:** His North Star is booked Oloxa meetings, and his own Build Plan says the durable edge is GTM *intelligence*, not shallow volume. The verify+QA stages are the point — on the first 8-lead run they caught unverifiable scraped signals (George's deal, Don's job ad traced to a different firm) and a direct-lender-vs-broker mismatch (Justin/Ascent), preventing credibility-killing sends.
