# Close Kit

Everything for the 24 hours after someone says yes. The rule: a verbal yes gets paperwork within the hour, payment the same day, and delivery starts the day payment lands.

## The flow

1. **Yes (call or email)** → send `SOW-trial.md` for the 14-Day Pipeline Proof ($2,000) immediately. Fill the blanks, drop in the payment link, send as PDF.
2. **Payment lands** → send `kickoff-questionnaire.md` + book the kickoff call for within 24 hours.
3. **Questionnaire back** → open `trial-week-runbook.md` and run it top to bottom.

`SOW-partnership-pilot.md` is a legacy exception, not a rep-selectable offer. Do not use it without Ryan's explicit approval.

## Why the urgency rule exists

Deals cool at night. The kit exists so the gap between "yes" and "paid" is measured in hours, and the gap between "paid" and "something delivered" is measured in one day.
