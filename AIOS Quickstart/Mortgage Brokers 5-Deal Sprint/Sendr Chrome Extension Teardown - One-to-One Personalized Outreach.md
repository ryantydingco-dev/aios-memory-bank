# Sendr Chrome Extension Teardown - One-to-One Personalized Outreach

Source: https://www.youtube.com/watch?v=vA0zIC4zeU8
Created: 2026-06-03

## Big idea

This video shows Sendr's Chrome extension for one-to-one personalized outreach from LinkedIn. The workflow creates a personalized page/video/proposal link for a specific lead without rebuilding the entire template every time.

For Ryan: this confirms Sendr is best used as a high-touch proof layer for top prospects or warm replies, not as the core cold email sender.

## What the video shows

1. Start with a lead on LinkedIn.
2. Use a Sendr template.
3. Add variables like company name.
4. Add a custom embed section.
5. Insert a `custom proposal` variable into the page/template.
6. Use the Chrome extension on the prospect profile.
7. Auto-pull normal variables.
8. Paste the custom proposal iframe/code manually.
9. Choose one of:
   - record new video
   - record audio note
   - use original page with lip sync personalization
10. Generate link.
11. Send it to the prospect via LinkedIn.

## What this means for Ryan's stack

### Smartlead remains the cold email engine

Smartlead should still own:

- plain-text cold email
- inbox rotation
- deliverability
- reply tracking
- sequence timing

Do not put Sendr links into every first cold email unless we intentionally test it.

### Sendr is a one-to-one proof layer

This video is literally about one-to-one personalized outreach. That means Sendr fits best for:

- top 25-100 highest-fit mortgage brokers
- LinkedIn conversations
- positive replies
- "send info" replies
- prospects who open/click/show intent
- prospects Ryan is willing to personally touch

### Salesfinity is the conversion hammer

After someone gets a Sendr page/video/proposal or replies to Smartlead:

- enrich phone
- call via Salesfinity
- reference the custom proposal
- book 15-minute workflow audit

## Recommended workflow

1. Smartlead sends plain text:

"Want me to send the 3 routines I’d set up for your team?"

2. If prospect says yes / maybe / send info:

Create Sendr page:

"3 AIOS routines I’d set up for {{company}}"

3. Page includes:

- Missing-doc follow-up drafts
- Daily pipeline brief
- Stale borrower/realtor follow-up queue
- Approval-only
- No sensitive borrower files needed for v1
- 7-day install

4. Message on LinkedIn/email:

"Made the quick version for {{company}} here — it shows the 3 routines I’d start with. Worth a 15-min look?"

5. Salesfinity call:

"Hey {{first_name}}, Ryan here — I sent over the 3-routine AIOS quick plan for {{company}}. I wanted to see if borrower doc follow-up, pipeline visibility, or stale borrower/realtor follow-ups are actually eating time for your team. Worth a quick 15 this week?"

## Caution

The Sendr custom proposal flow still requires manual thought. If Ryan tries to make 250 of these before sending, it will become procrastination wearing a SaaS hoodie.

Use it for high-fit/warm people only.

## One-line lesson

Sendr's Chrome extension is best for high-touch one-to-one proof assets after a lead is worth the attention — Smartlead creates reach, Sendr creates validity, Salesfinity turns that validity into meetings.
