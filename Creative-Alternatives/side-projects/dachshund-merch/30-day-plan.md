# 30-day game plan → first sale by 2026-08-12

**Definition of done:** one sale to a stranger (not friends/family) through the store, driven by content or ads. Friends/family orders count as QA, not the win.

**The critical path is TikTok Shop approval and sample printing — start both in Week 1.** Content starts Day 1; audience-building never waits for the store.

---

## Week 1 (Jul 14–20) — Decisions & foundations

**Blocking decisions (resolve with Kenny in one 30-min conversation):**
- [ ] **Decoration method for one-offs** — DTF/DTG available, or screen-print only? This decides everything downstream.
  - If DTF/DTG: true on-demand, print as orders arrive.
  - If screen-print only: weekly internal batch window ("ships in 5–7 days") OR outsource DTF transfers (gang sheets are cheap, press in-house). Either works; pick one.
- [ ] **True one-off unit cost** per product (blank + print + labor + poly mailer + shipping). Sets the pricing floor. Target ≥65% gross margin (see designs.md).

**Setup:**
- [ ] Pick brand name + secure handles (TikTok, IG, domain) — shortlist in content-plan.md
- [ ] Confirm dogs' names in docs `[CONFIRM]`
- [ ] Shopify store started (theme can be default; don't polish)
- [ ] **Apply for TikTok Shop immediately** — approval takes days-to-weeks; it's the long pole
- [ ] Pick 10 launch designs from designs.md; start art files
- [ ] Order blank samples from SanMar (tees, crewnecks, hats, bandana material)
- [ ] **Post first dog video.** No product, no brand mention needed. The account starts aging today.

## Week 2 (Jul 21–27) — Product & store

- [ ] Finalize 10 print-ready art files
- [ ] Print full sample run in-house
- [ ] Product shoot: dogs in/with every design + flat lays + matching sets (one afternoon)
- [ ] Load products into Shopify: photos, prices, sizes; write listings in-voice
- [ ] Shipping setup: flat-rate or free-over-$50; poly mailers ordered
- [ ] Keep posting (4–5 this week, dog content + first print-shop teasers: "we're making something")
- [ ] Legal/ops quick pass: sales channel under CA's entity or DBA? Sales tax nexus = existing CA setup `[CONFIRM with Kenny/accountant — 15 min]`

## Week 3 (Jul 28–Aug 3) — Launch

- [ ] Store live (Shopify) + TikTok Shop connected if approved
- [ ] **Launch video:** "Our family has owned a print shop for 27 years. We just gave our wiener dogs their own merch line." Pin it.
- [ ] Daily posting this week (launch surge): design reveals, matching sets, comment-to-print kickoff
- [ ] Friends & family test orders → verify checkout, print queue, ship times (QA, not sales)
- [ ] Seed gently: 2–3 dachshund Facebook groups / subreddits where selling is allowed — share the story (family print shop + dogs), not a sales pitch
- [ ] Start weekly metrics log in content-plan.md

## Week 4 (Aug 4–12) — Traffic & first sale

- [ ] Maintain 4–5 posts/week
- [ ] **Paid test:** take the best-performing organic video, run TikTok Spark Ads + IG Boost at $20–30/day. Budget cap for the test: $500. Expect this to teach, not return — anything better is upside.
- [ ] TikTok Shop affiliate program on (open commission to pet creators; affiliate GMV is ~half of sales for some pet brands)
- [ ] Comment-to-print video #2 (engagement flywheel)
- [ ] **First stranger sale target: Aug 12.** When it lands: film the reaction, pack-an-order video, thank-you card in the mailer (handwritten, from the dogs).

## Kill/scale criteria (judge at Day 60, not Day 30)

- **Scale** if: any video >100K views, OR 1K+ followers, OR 10+ stranger sales, OR paid CPA < gross profit per order.
- **Iterate** if: content grows but no conversion → fix store/pricing/offer, not the content.
- **Park** if: 60 days of consistent posting (20+ posts) with flat views AND zero sales — write the post-mortem, keep the always-on-store playbook for the camp-store upsell (the R&D still pays).

## What this project must produce even if the brand fails

1. The **always-on store playbook**: platform, on-demand print cadence, shipping flow → productize as year-round camp/org stores for CA clients.
2. **Pillar 4 content**: the whole arc is an episode ("we launched a merch brand from a 27-year-old print shop in 30 days").
3. **Real one-off unit costs** for on-demand decoration — useful for pricing any future CA on-demand offer.
