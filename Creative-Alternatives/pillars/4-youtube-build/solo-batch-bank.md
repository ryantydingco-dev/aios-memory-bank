## The batch rule
**One setup per session.** Don't flip between camera-talk and screen-record mid-batch — group by setup and rip. You record 8 in the time it takes to set up once. Same shirt? Change it halfway so the 8 don't look identical when posted.

## 3 setups = 3 kinds of batch day
1. **Talking-head** — camera, you, just talk. Teaching / listicles / opinions / story. *No data, no prep — shoot today.*
2. **Screen-demo** — screen-record + voice. "I used AI to ___." Some need a one-time data pull (★).
3. **Shorts** — rapid screen-record, one prompt each, 30–45s.

## The infinite engine (you will never run dry)
**5 content veins** — each spins out endless videos:
1. **AI tools** — "I used [tool] to [business task]."
2. **AI prompts** — "the exact prompt I use to [X]" (your best Shorts).
3. **Business-function automations** — quotes, invoicing, email, scheduling, inventory, proofs, support, marketing, hiring — one video each.
4. **Story / contrarian** — the AOL email, "$3M on word of mouth," "no systems."
5. **Reactions / opinions** — tool reviews, "every small business wastes time on X."

**Multipliers:**
- Every long-form → **cut 3–5 Shorts** (the hook, the result, the on-screen prompt). 8 long-forms = 30+ Shorts for free.
- Re-skin a winner: a video that pops → make "Part 2," the opposite take, or the same idea for a different function.
- **Ask me for "30 more in [vein]"** and I hunt + CTR-score a fresh batch in minutes.

## Record-card format (so 8-in-a-sitting actually works)
Don't write 8 full scripts — you won't read a teleprompter 8 times. Each video = **a hook line + 3–5 value bullets + the like-CTA + a sign-off.** You riff from the card. Fast, natural, batchable.
