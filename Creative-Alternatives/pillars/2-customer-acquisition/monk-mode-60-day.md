# Monk Mode — 60 Days (Aug 10 – Oct 6)

Written 2026-08-09, the night before all three campaigns go live. Ryan's ask: map the
sales acquisition path so the anxiety has somewhere to go, and structure all-day-every-day
work on the business.

## The one reframe that kills the anxiety

Anxiety is not knowing whether today counted. A paycheck used to answer that question
every two weeks. The replacement is a **daily scoreboard of numbers you control** — not
revenue (you don't control when someone signs a PO) but the five actions that produce it:

| # | Daily number | Target |
|---|---|---|
| 1 | Reactivation dials | 8-10 |
| 2 | Replies answered with a mockup started same day | 100% |
| 3 | Follow-ups sent (day-3 / day-8 cadence) | all due |
| 4 | $ quoted (proposals out the door) | log it |
| 5 | $ closed, Ryan-originated | log it |

Log all five every night, 10 minutes, in the pipeline tracker. If numbers 1-3 are green
for a week and nothing closes, the plan is wrong and we fix the plan — but you sleep,
because YOU did the work. That is the entire mental trade: swap "am I okay?" for
"did I hit my five numbers?"

## The monk-mode day (Mon-Fri)

| Block | What | Rule |
|---|---|---|
| 8:00-9:00 | Inbox sweep: triage campaign replies, mark queue statuses | Every reply gets a same-day mockup started |
| 9:00-11:00 | **PHONE BLOCK — 8-10 reactivation dials** | The one immovable block. Business hours are the asset the layoff gave you |
| 11:00-12:00 | Build the morning's mockups/lookbooks (ca-production-art) | |
| 12:00-1:00 | Lunch + gym | Non-negotiable. Monk mode with no recovery is a two-week sprint, not a two-month one |
| 1:00-2:30 | Follow-ups: everything due on day-3/day-8 cadence, deal-board pushes | |
| 2:30-4:30 | Deal work: quotes with Kenny (sit in on every one — this is the apprenticeship), proposals out | |
| 4:30-5:30 | ONE growth block: next segment's list, next week's prep | Only one. Building is capped so selling isn't |
| Evening | Scoreboard: log the 5 numbers, set tomorrow's call list | 10 min, then stop |

**Saturday:** half day — replies and Monday prep only. **Sunday: off.** A rest day is
part of monk mode, not a violation of it. You're building a 27-year business, not a
27-day one.
