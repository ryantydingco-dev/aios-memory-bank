# Import — drop zone

Drop raw material here for Claude to read and fold into the workspace. Examples:

- Kenny's spreadsheets (orders, customers, suppliers, pricing)
- Existing SOPs, quote templates, or order forms
- Screenshots of current tools / workflows
- Exports from QuickBooks, the website, or any order system
- Past proposals, decks, or customer emails
- Notes from shadowing Kenny/Maclaine through a real order

## How to use it

1. Drop the file(s) here.
2. In a session, tell Claude what it is and what you want done with it.
3. Claude reads it, extracts what matters, and updates the relevant `context/` file or pillar — marking anything uncertain `[CONFIRM]`.

Raw dumps stay here; clean, structured knowledge graduates into `context/` and `pillars/`. Don't leave the only copy of something important in here.
